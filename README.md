# From-Entity-Relationship-Diagrams-to-Data-Visualisations-in-Power-BI-Desktop

1.	Project Title/Headline
From Entity Relationship Diagrams to Data Visualisations in Power BI Desktop.

2.	Short Description/ Purpose
My goal was to present a road from creating the Entity Relationship Diagrams to build Data Visualisation in Power BI.

3.	The project was done using the following tools and technologies:
   
Lucid.app:

•	Building ERD – creating six entities, each entity consists of a title, attributes names and their data types, primary key and foreign key. 
•	Adding relationships between Entities - all are connected by 1: many relationships
•	Exporting ERD to SQL Server Management Studio

SQL Server Management Studio:
•	Adding new Database to execute exported Tables
•	Adding Values to created tables using commend “Insert Into”

Power BI Desktop:
•	Using created Tables as a Data Source in Power BI Desktop
•	DAX language - used to add Calendar Table
•	Data Modelling - establishing relationships between Tables and Calendar Table
•	Data Visualisations – visuals used:
    o	Clustered column chart
    o	Tree map
    o	Pie chart
    o	Decomposition Tree
File format .pbix for development .png for dashboard previews
